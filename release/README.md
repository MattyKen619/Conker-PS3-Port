# Your own XMB pictures (optional)

Put `ICON0.local.png` (a 320 x 176 icon, with transparency) and/or `PIC1.local.png` (a 1920 x 1080
background) here before `make -C app RELEASE=1 pkg`, and the package carries them. Without an icon of your
own, the game makes one from the title screen of your ROM the first time it runs.

These files are ignored by git: a game's logo and artwork belong to its publisher.
